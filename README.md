# PubMed Literature Workflow — Web Edition

[中文说明](README.zh-CN.md)

Browser-based PubMed search, Excel export, and Markdown reading packages for use with AI assistants.

## Quick start

Open `index.html` in a current Chrome or Edge browser with an internet connection. Enter a PubMed query and contact email; an NCBI API key is optional.

## Scope

This is the web edition. AI summaries require checking against the original papers. Bundled dependency notices are preserved in `第三方软件许可.txt`.

This repository preserves the supplied tool files. Upload checks cover file integrity and Python syntax where applicable; they do not establish scientific validation or end-to-end application testing.
