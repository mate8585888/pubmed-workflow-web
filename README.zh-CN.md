# PubMed 文献工作流 · 网页版

[English](README.md)

在浏览器中检索 PubMed，导出 Excel 文献表、原始记录和供 AI 阅读的 Markdown 分包。

## 开始使用

使用联网的 Chrome 或 Edge 打开 `index.html`，输入检索式和联系邮箱。NCBI API Key 为可选项。完整操作与追问模板见 [网页版使用说明](网页版使用说明.txt)。

## 适用范围

本仓库为网页版。AI 总结须回到原文核对；第三方依赖许可见 [第三方软件许可](第三方软件许可.txt)。
